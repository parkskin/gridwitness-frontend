# GridWitness 프로그램 전체 점검 — 2026-11-10

## 범위와 확인 방법

ParksKin 프론트 `main`의 `a54e534`를 기준으로 화면 진입 경로, 프론트 API 호출, 저장 계약, 설명 문서, 자동 회귀 시험, 운영 웹/API의 읽기 전용 응답을 확인했습니다. 운영 데이터에는 쓰기 요청을 보내지 않았습니다.

## 수정한 결함

- 설정 화면은 Ollama의 `/api/tags` 모델 목록 확인을 실제 답변 생성 성공처럼 표시하고 있었습니다. 이제 “주소 응답 확인”과 “대화에서 실제 답변 채택 여부 확인”을 나눠 표시합니다.
- 한전 사용량 화면이 공통 API 요청 함수를 거치지 않아 설정된 접근 토큰과 공통 시간 제한·오류 처리를 적용하지 않았습니다. `getKepcoUsagePage`로 통일했습니다.
- 화면 설명서의 CORS 호스트가 이전 저장소 `jyx-07.github.io`로 남아 있었습니다. 현재 ParksKin Pages 주소와 로컬/Vercel 프록시 동작을 반영했습니다.
- 로직 설명서가 서버 분석은 늘 보류라고 적고, RU 5채널 모델 계약을 빠뜨렸습니다. 현재 CN/RU 입력 계약과 서버 응답 기준으로 고쳤습니다.
- README의 점검 계획 링크가 이 브랜치에 없는 파일을 가리키고 있어 실제 점검 결과 문서 링크로 바꿨습니다.

## 운영 상태를 읽기 전용으로 확인

- `https://parkskin.github.io/gridwitness-frontend/`는 HTTP 200이고, HTML에서 참조하는 JS/CSS 13개도 모두 HTTP 200입니다. 확인한 배포 시각은 `2026-11-10 09:23:02 UTC`입니다.
- API `/health`는 데이터베이스 준비 상태로 응답했습니다. ParksKin 출처의 CORS preflight는 HTTP 200이며 POST/PUT와 authorization/content-type 헤더를 허용했습니다.
- `/capabilities`는 CN Xiong·RU OscGrid 분류 모델을 사용 가능으로 응답했습니다. 저장된 시연 사건의 기존 분석 조회는 `completed`, `PF`를 반환했습니다. 이는 전체 데이터의 정확도나 신규 분석 실행 성공을 보증하지 않습니다.
- LLM 설정은 `qwen2.5:3b`, 인증은 `required: false`로 응답했습니다. LLM `available`은 모델 목록 응답 가능성만 뜻합니다. 앞서 확인된 생성 시간 초과와 모델 라이선스·GPU 문제는 해결된 것으로 볼 수 없습니다.
- 브라우저/USB를 이번 점검에서 열어 장치를 점유하지 않았습니다. 이전 실측 기록은 `COM19`, INA219 `0x40` 응답, `0x41` 미응답입니다. 따라서 현재 상태에서 가로등 구간 실측은 증명되지 않았습니다. Windows 장치 목록에는 Arduino Uno `COM19`가 연결된 것으로 보였습니다.
- 운영 API는 인증이 꺼져 있으므로 주소를 아는 사용자가 사건을 읽고 쓸 수 있는 공개 시연 상태입니다.

## 검증 결과

- 프론트 회귀 시험: `npm test` 43/43 통과.
- 프로덕션 빌드: `npm run build` 성공. 기존 경고는 500KB 초과 3D 라벨 청크와 `CaseDetail`의 ineffective dynamic import입니다.
- 린트: `npm run lint -- --format json` 오류 0건, 경고 29건. 이 중 일부는 개발 HMR/Three.js의 의도된 객체 갱신이며, 경고 수만으로 사용자 기능 결함이라고 판단하지 않았습니다.
- 실제 USB 장치 → 브라우저 → 운영 API 저장 → 재조회 흐름은 본 점검에서 다시 실행하지 않았습니다. 이전 기록의 우노 측정과 API 파형 저장 증거는 별도이며, 이번 코드 변경을 운영 배포한 뒤의 통합 검증은 아닙니다.
- 설치된 Chromium/Edge의 headless DOM 실행은 `Multiple targets are not supported in headless mode` 오류로 화면 렌더 확인에 실패했습니다. 따라서 실제 브라우저에서 각 경로를 클릭하는 시각·모바일 검증은 미확인입니다.
- 수정 사항은 `parkskin/gridwitness-frontend`의 `fix/full-program-audit` 브랜치에 푸시했고 [Draft PR #2](https://github.com/parkskin/gridwitness-frontend/pull/2)를 열었습니다. 위 운영 페이지 응답은 수정 전 배포본이므로 수정 사항이 실제 사용자 웹에 반영됐다고 보면 안 됩니다.

## 운영 전 남은 외부 조건

- 가로등 센서 `0x41` 및 조합 기준표 이상 `00011`은 배선·센서 수리 후 재측정이 필요합니다.
- LLM 생성 경로는 실제 답변·시간 제한·라이선스 조건을 GPU 서버에서 다시 검증해야 합니다.
- 공개 API의 익명 쓰기를 유지할지, 토큰을 배포해 접근을 제한할지 운영 설정을 결정해야 합니다.
- 학교 서버 만료 전에 백업·이전 절차가 필요합니다.
